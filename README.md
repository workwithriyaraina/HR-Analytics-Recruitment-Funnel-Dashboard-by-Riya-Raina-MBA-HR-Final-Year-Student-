# HR-Analytics-Recruitment-Funnel-Dashboard-by-Riya-Raina-MBA-HR-Final-Year-Student-
This project showcases an HR Analytics Mini Project built in MS Excel to analyze the recruitment funnel. Using a dummy dataset of 200+ candidates, I created an interactive dashboard to track hiring efficiency, source effectiveness, department demand, and time-to-hire (TAT).

-Features

1.Recruitment Funnel Analysis – applications to hires, drop-off insights
2.Source Effectiveness – LinkedIn vs. Naukri vs. Referrals vs. Campus
3.Department Hiring Trends – Sales, IT, HR, Marketing, Finance
4.Turnaround Time (TAT) – stage-wise average hiring time
5.Interactive Dashboard – charts, pivot tables, and slicers
6.Insights & Recommendations – humanized interpretations for HR decision-making

-Key Insights

1.Most drop-offs occur during interviews, suggesting stronger early screening is needed.
2.LinkedIn generates volume, while referrals & campus hires deliver quality.
3.Sales & IT dominate hiring demand, reflecting business growth focus.
4.Interview & offer stages create hiring delays; reducing them can cut TAT by ~20%.
