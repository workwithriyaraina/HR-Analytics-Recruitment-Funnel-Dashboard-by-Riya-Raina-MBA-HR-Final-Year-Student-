# HR-Analytics-Recruitment-Funnel-Dashboard-by-Riya-Raina-MBA-HR-Final-Year-Student-
This project showcases an HR Analytics Mini Project built in MS Excel to analyze the recruitment funnel. Using a dummy dataset of 200+ candidates, I created an interactive dashboard to track hiring efficiency, source effectiveness, department demand, and time-to-hire (TAT).

Features

Recruitment Funnel Analysis – applications to hires, drop-off insights

Source Effectiveness – LinkedIn vs. Naukri vs. Referrals vs. Campus

Department Hiring Trends – Sales, IT, HR, Marketing, Finance

Turnaround Time (TAT) – stage-wise average hiring time

Interactive Dashboard – charts, pivot tables, and slicers

Insights & Recommendations – humanized interpretations for HR decision-making

🔎 Key Insights

Most drop-offs occur during interviews, suggesting stronger early screening is needed.

LinkedIn generates volume, while referrals & campus hires deliver quality.

Sales & IT dominate hiring demand, reflecting business growth focus.

Interview & offer stages create hiring delays; reducing them can cut TAT by ~20%.
